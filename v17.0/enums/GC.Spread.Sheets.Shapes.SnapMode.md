### <a id="grid" name="grid"></a> grid

• **grid** = `1`

调整形状大小或移动形状时，靠近网格线，形状将捕捉到网格线

___

### <a id="none" name="none"></a> none

• **none** = `0`

调整或移动形状时，不捕捉到任何参照位置

___

### <a id="shape" name="shape"></a> shape

• **shape** = `2`

调整形状大小或移动形状时，靠近其他形状边界，形状将捕捉到边界
