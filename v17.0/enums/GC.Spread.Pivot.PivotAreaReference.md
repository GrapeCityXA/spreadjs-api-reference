# Enumeration: PivotAreaReference

[Spread](../modules/GC.Spread.md).[Pivot](../modules/GC.Spread.Pivot.md).PivotAreaReference

Specifies the whether automatically generate the getPivotData formula or cell reference when choose pivot table data area. Default is getPivotData.

### Enumeration members

- [cellReference](GC.Spread.Pivot.PivotAreaReference.md#cellreference)

## Enumeration members

### <a id="cellreference" name="cellreference"></a> cellReference

• **cellReference** = `0`

Generate normal cell reference.

___

### <a id="getpivotdata" name="getpivotdata"></a> getPivotData

• **getPivotData** = `1`
