[Sheets](../modules/GC.Spread.Sheets.md).[Shapes](../modules/GC.Spread.Sheets.Shapes.md).LineJoinStyle

指定两条相交线条的拐角样式。

## Enumeration members

### <a id="bevel" name="bevel"></a> bevel

• **bevel** = `2`

指定两线相交处的拐角为45度斜切角。

___

### <a id="miter" name="miter"></a> miter

• **miter** = `1`

指定两线相交处的拐角为斜接角。

___

### <a id="round" name="round"></a> round

• **round** = `0`

指定两线相交处的拐角为圆角。
