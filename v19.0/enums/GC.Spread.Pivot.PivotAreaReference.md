# Enumeration: PivotAreaReference

[Spread](../modules/GC.Spread.md).[Pivot](../modules/GC.Spread.Pivot.md).PivotAreaReference

指定选择数据透视表数据区域时是否自动生成 getPivotData 公式或单元格引用。默认值为 getPivotData。
