# Enumeration: GroupLayoutMode

[Sheets](../modules/GC.Spread.Sheets.md).[TableSheet](../modules/GC.Spread.Sheets.TableSheet.md).GroupLayoutMode

定义分组布局的显示方式。

**`example`**
```
// 此示例展示如何将分组布局模式更改为大纲模式。
tableSheet.options.groupLayout={ mode: GC.Spread.Sheets.TableSheet.GroupLayoutMode.outline };
```

## Enumeration members

### <a id="condensed" name="condensed"></a> condensed

• **condensed** = `2`

指定分组布局为紧凑模式。

___

### <a id="outline" name="outline"></a> outline

• **outline** = `1`

指定分组布局为大纲模式。

___

### <a id="tabular" name="tabular"></a> tabular

• **tabular** = `0`

指定分组布局为表格模式。
