### <a id="all" name="all"></a> all

• **all** = `3`

无论列值是自有字段、相关字段还是计算字段都显示。

___

### <a id="field" name="field"></a> field

• **field** = `1`

当列值是自有字段或相关字段时显示。

___

### <a id="formula" name="formula"></a> formula

• **formula** = `2`

当列值是计算字段时显示。

___

### <a id="none" name="none"></a> none

• **none** = `0`

不显示列值。
