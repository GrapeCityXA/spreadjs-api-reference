## Properties

### <a id="height" name="height"></a> height

• `Optional` **height**: `number`

图表图例的高度，它是百分比，并且基于图表的高度。

___

### <a id="width" name="width"></a> width

• `Optional` **width**: `number`

图表图例的宽度，它是百分比，并且基于图表的宽度。

___

### <a id="x" name="x"></a> x

• `Optional` **x**: `number`

图表图例的 x 位置，它是百分比，基线是图表的左边缘。

___

### <a id="y" name="y"></a> y

• `Optional` **y**: `number`

图表图例的 y 位置，它是百分比，基线是图表的上边缘。
