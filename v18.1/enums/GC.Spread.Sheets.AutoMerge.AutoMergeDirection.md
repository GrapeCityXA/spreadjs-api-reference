## Enumeration members

### <a id="column" name="column"></a> column

• **column** = `1`

表示在列方向上应用自动合并。

___

### <a id="columnrow" name="columnrow"></a> columnRow

• **columnRow** = `3`

表示优先在列方向上应用自动合并，然后在行方向上应用。

___

### <a id="none" name="none"></a> none

• **none** = `0`

表示取消自动合并。

___

### <a id="row" name="row"></a> row

• **row** = `2`

表示在行方向上应用自动合并。

___

### <a id="rowcolumn" name="rowcolumn"></a> rowColumn

• **rowColumn** = `4`

表示优先在行方向上应用自动合并，然后在列方向上应用。
