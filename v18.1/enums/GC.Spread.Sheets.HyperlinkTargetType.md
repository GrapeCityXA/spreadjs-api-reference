# Enumeration: HyperlinkTargetType

[Spread](../modules/GC.Spread.md).[Sheets](../modules/GC.Spread.Sheets.md).HyperlinkTargetType

表示用户打开超链接文档的方式。默认为blank。

## Enumeration members

### <a id="blank" name="blank"></a> blank

• **blank** = `0`

在新窗口或标签页中打开超链接文档。

___

### <a id="parent" name="parent"></a> parent

• **parent** = `2`

在父框架中打开超链接文档。

___

### <a id="self" name="self"></a> self

• **self** = `1`

在用户点击的同一框架中打开超链接文档。

___

### <a id="top" name="top"></a> top

• **top** = `3`

在窗口的完整主体中打开超链接文档。
