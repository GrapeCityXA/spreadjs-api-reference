### <a id="align" name="align"></a> align

• `Optional` **align**: [`AlignType`](../modules/GC.Spread.Sheets.StatusBar.StatusItem.md#aligntype)

控制状态栏上项目的对齐方式。值为'left'或'right'。

___

### <a id="menucontent" name="menucontent"></a> menuContent

• `Optional` **menuContent**: `string`

在上下文菜单左侧显示的菜单内容，代表当前项目。

___

### <a id="showstatusincontexmenu" name="showstatusincontexmenu"></a> showStatusInContexMenu

• `Optional` **showStatusInContexMenu**: `boolean`

是否在上下文菜单右侧显示状态。

___

### <a id="tiptext" name="tiptext"></a> tipText

• `Optional` **tipText**: `string`

鼠标悬停在项目上时显示的提示文本。显示项目的描述。

___

### <a id="value" name="value"></a> value

• `Optional` **value**: `any`

在状态栏和上下文菜单右侧显示的值，用于表示当前项目的状态。

___

### <a id="visible" name="visible"></a> visible

• `Optional` **visible**: `boolean`

1.状态栏上当前项目的可见性。2.上下文菜单中当前项目的选中状态。
