## Enumeration members

### <a id="double" name="double"></a> double

• **double** = `1`

指定在形状路径两侧显示两条线条

___

### <a id="simple" name="simple"></a> simple

• **simple** = `0`

仅指定在形状路径周围显示一条线条

___

### <a id="thickthin" name="thickthin"></a> thickThin

• **thickThin** = `2`

指定两条线条：一条粗线显示在形状外部范围，另一条细线显示在形状内部范围

___

### <a id="thinthick" name="thinthick"></a> thinThick

• **thinThick** = `3`

指定两条线条：一条细线显示在形状外部范围，另一条粗线显示在形状内部范围

___

### <a id="triple" name="triple"></a> triple

• **triple** = `4`

指定三条线条：一条粗线显示在形状路径周围，另外两条细线分别显示在形状内部和外部范围
