# Enumeration: ResizeMode

[Spread](../modules/GC.Spread.md).[Sheets](../modules/GC.Spread.Sheets.md).ResizeMode

指定调整大小的使用方式。

**`example`**
```
//此示例展示如何指定调整大小的方式。
spread.options.columnResizeMode = GC.Spread.Sheets.ResizeMode.split;
spread.options.rowResizeMode = GC.Spread.Sheets.ResizeMode.normal;
```
