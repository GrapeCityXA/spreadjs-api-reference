# Enumeration: AllowDragHeaderToMove

[Spread](../modules/GC.Spread.md).[Sheets](../modules/GC.Spread.Sheets.md).AllowDragHeaderToMove

指定如何允许拖动标题移动。

## Table of contents

### Enumeration members

- [both](GC.Spread.Sheets.AllowDragHeaderToMove.md#both)
- [column](GC.Spread.Sheets.AllowDragHeaderToMove.md#column)
- [none](GC.Spread.Sheets.AllowDragHeaderToMove.md#none)
- [row](GC.Spread.Sheets.AllowDragHeaderToMove.md#row)

## Enumeration members

### <a id="both" name="both"></a> both

• **both** = `3`

指定列标题和行标题都允许移动。

___

### <a id="column" name="column"></a> column

• **column** = `1`

指定仅列标题允许移动。

___

### <a id="none" name="none"></a> none

• **none** = `0`

指定不允许移动拖动标题。

___

### <a id="row" name="row"></a> row

• **row** = `2`

指定仅行标题允许移动。
