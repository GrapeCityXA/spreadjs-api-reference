### <a id="definecolumn" name="definecolumn"></a> DefineColumn

• **DefineColumn**: `Object`

表示用于定义列的命令。

**`property`** {boolean} canUndo - 指示命令是否支持撤销和重做操作。

**`property`** {function} execute - 执行或撤销操作。

execute方法的参数如下。

**`property`** {GC.Spread.Sheets.Workbook} context - 操作的上下文。

**`property`** {Object} options - 操作的选项。

**`property`** {string} options.sheetName - 工作表名称。

**`property`** {number} [options.col] 插入的指定列，可选。

**`property`** {GC.Data.IColumn} options.column - 定义的列。

**`property`** {boolean} isUndo - 如果是撤销操作则为`true`；否则为`false`。

**`example`**
```javascript
// 此示例使用定义列操作。
// 定义列属性
spread.commandManager().execute({cmd: "DefineColumn", sheetName: "Sheet1", { col: 1, column: { value: 'column1' }}});
```

#### Type declaration

| Name | Type |
| :------ | :------ |
| `canUndo` | `boolean` |
| `execute` | (`context`: [`Workbook`](../classes/GC.Spread.Sheets.Workbook.md), `options`: { `col?`: `number` ; `column`: [`IColumn`](GC.Data.md#icolumn) ; `sheetName`: `string`  }) => `any` |

### <a id="endtransaction" name="endtransaction"></a> endTransaction

▸ **endTransaction**(`context`, `options`): `void`

结束事务。在事务期间，数据模型的更改将被保存。

**`property`** {GC.Spread.Sheets.Workbook} context - 操作的上下文。

**`property`** {Object} options - 操作的选项。

**`property`** {string|string[]} [options.sheetName] 工作表名称。如果当前事务需要更改多个工作表，则sheetName可以是字符串数组。

**`example`**
```javascript
// 例如，以下代码注册changeBackColor命令然后执行该命令。
var command = {
  canUndo: true,
  execute: function (context, options, isUndo) {
    var Commands = GC.Spread.Sheets.Commands;
    options.cmd = "changeBackColor";
    if (isUndo) {
      Commands.undoTransaction(context, options);
      return true;
    } else {
      Commands.startTransaction(context, options);
      var sheet = context.getSheetFromName(options.sheetName);
      var cell = sheet.getCell(options.row, options.col);
      cell.backColor(options.backColor);
      Commands.endTransaction(context, options);
      return true;
    }
  }
};
var spread = GC.Spread.Sheets.findControl(document.getElementById("ss"));
var commandManager = spread.commandManager();
commandManager.register("changeBackColor", command);
commandManager.execute({cmd: "changeBackColor", sheetName: spread.getSheet(0).name(), row: 1, col: 2, backColor: "red"});
```

| Name | Type |
| :------ | :------ |
| `context` | [`Workbook`](../classes/GC.Spread.Sheets.Workbook.md) |
| `options` | `any` |

`void`
