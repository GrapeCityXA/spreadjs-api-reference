## Enumeration members

### <a id="custom" name="custom"></a> custom

• **custom** = `0`

指定误差线具有自定义值类型，每个误差线都有自己的值，各个值可能不同。

___

### <a id="fixedvalue" name="fixedvalue"></a> fixedValue

• **fixedValue** = `1`

指定每个数据点的误差线具有固定值类型。

___

### <a id="percentage" name="percentage"></a> percentage

• **percentage** = `2`

指定每个数据点的误差线具有百分比值类型。

___

### <a id="standarddeviation" name="standarddeviation"></a> standardDeviation

• **standardDeviation** = `3`

指定每个数据点的误差线具有计算的标准差值类型。

___

### <a id="standarderror" name="standarderror"></a> standardError

• **standardError** = `4`

指定每个数据点的误差线具有计算的标准误差值类型。
