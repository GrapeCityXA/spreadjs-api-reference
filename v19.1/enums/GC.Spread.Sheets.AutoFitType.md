# Enumeration: AutoFitType

[Spread](../modules/GC.Spread.md).[Sheets](../modules/GC.Spread.Sheets.md).AutoFitType

表示组件是否自动调整单元格或表头的大小。

**`example`**
```javascript
//此示例使用 AutoFitType 枚举。
spread.options.autoFitType = GC.Spread.Sheets.AutoFitType.cellWithHeader;
```
