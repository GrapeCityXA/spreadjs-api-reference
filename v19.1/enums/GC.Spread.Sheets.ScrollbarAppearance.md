# Enumeration: ScrollbarAppearance

[Spread](../modules/GC.Spread.md).[Sheets](../modules/GC.Spread.Sheets.md).ScrollbarAppearance

指定垂直和水平滚动条的外观。

**`example`**
```javascript
//此示例展示移动滚动条模式。
spread.options.scrollbarAppearance = GC.Spread.Sheets.ScrollbarAppearance.mobile;
```

## Table of contents

### Enumeration members

- [mobile](GC.Spread.Sheets.ScrollbarAppearance.md#mobile)
- [skin](GC.Spread.Sheets.ScrollbarAppearance.md#skin)

## Enumeration members

### <a id="mobile" name="mobile"></a> mobile

• **mobile** = `1`

指定时尚的移动滚动条外观，可以自定义。

___

### <a id="skin" name="skin"></a> skin

• **skin** = `0`

指定Excel风格的经典滚动条外观。
