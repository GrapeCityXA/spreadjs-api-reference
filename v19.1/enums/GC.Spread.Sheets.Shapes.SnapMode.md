## Enumeration members

### <a id="grid" name="grid"></a> grid

• **grid** = `1`

调整大小或移动形状时，靠近网格线则吸附到网格线。

___

### <a id="none" name="none"></a> none

• **none** = `0`

调整大小或移动形状时，不吸附到任何参考位置。

___

### <a id="shape" name="shape"></a> shape

• **shape** = `2`

调整大小或移动形状时，靠近其他形状边界则吸附到边界。
