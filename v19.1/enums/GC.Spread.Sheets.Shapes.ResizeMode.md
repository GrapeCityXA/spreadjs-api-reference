# Enumeration: ResizeMode

[Sheets](../modules/GC.Spread.Sheets.md).[Shapes](../modules/GC.Spread.Sheets.Shapes.md).ResizeMode

指定形状大小调整模式。

### Enumeration members

- [horizontal](GC.Spread.Sheets.Shapes.ResizeMode.md#horizontal)
- [vertical](GC.Spread.Sheets.Shapes.ResizeMode.md#vertical)

## Enumeration members

### <a id="aspect" name="aspect"></a> aspect

• **aspect** = `0`

显示所有调整控点，使用[NW（西北）、NE（东北）、SW（西南）、SE（东南）]控点调整形状时，将保持形状的纵横比。

___

### <a id="horizontal" name="horizontal"></a> horizontal

• **horizontal** = `1`

仅显示[W（西）、E（东）]调整控点，调整形状时仅能改变宽度。

___

### <a id="vertical" name="vertical"></a> vertical

• **vertical** = `2`

仅显示[N（北）、S（南）]调整控点，调整形状时仅能改变高度。
