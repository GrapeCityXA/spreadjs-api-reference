## Enumeration members

### <a id="active" name="active"></a> active

• **active** = `16`

当单元格获得焦点时，单元格状态包含"活动"状态。

___

### <a id="dirty" name="dirty"></a> dirty

• **dirty** = `64`

当单元格值发生变化时，单元格状态包含"已修改"状态。

___

### <a id="edit" name="edit"></a> edit

• **edit** = `8`

当单元格正在编辑时，单元格状态包含"编辑"状态。

___

### <a id="hover" name="hover"></a> hover

• **hover** = `1`

当鼠标悬停在单元格上时，单元格状态包含"悬停"状态。

___

### <a id="invalid" name="invalid"></a> invalid

• **invalid** = `2`

当数据验证条件评估失败时，单元格状态包含"无效"状态。

___

### <a id="invalidformula" name="invalidformula"></a> invalidFormula

• **invalidFormula** = `128`

当单元格值为无效公式字符串时，单元格状态包含"无效公式"状态。

___

### <a id="readonly" name="readonly"></a> readonly

• **readonly** = `4`

当单元格在受保护的工作表中被锁定时，单元格状态包含"只读"状态。

___

### <a id="selected" name="selected"></a> selected

• **selected** = `32`

当单元格在选定范围内时，单元格状态包含"已选择"状态。
