## Constructors

### <a id="constructor" name="constructor"></a> constructor

• **new ThemeFonts**()

表示内置主题的主题字体。

**`example`**
```javascript
//此示例创建一个自定义主题。
var custom = new GC.Spread.Sheets.Theme("CustomTheme");
custom.font(GC.Spread.Sheets.ThemeFonts.Office);
activeSheet.currentTheme(custom);
```
